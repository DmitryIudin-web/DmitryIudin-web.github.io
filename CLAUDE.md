# CLAUDE.md — инструкции для AI-агентов (Claude Code, Codex и др.)

> **Канон — этот файл.** `AGENTS.md` — его байтовое зеркало для Codex.
> Правьте только `CLAUDE.md`, затем `python3 scripts/sync_agent_docs.py`.

Репозиторий — статический сайт **avtonds.ru** (ООО «АСТ»: премиальные автомобили
под заказ, авто с НДС для юрлиц, лизинг). Статика: Tilda/Astro-экспорт,
без сборки и без бэкенда. Язык контента — русский.

## Критичные правила

1. **Сохраняй байтовую структуру страниц.** `.gitattributes` содержит `* -text`:
   большинство `index.html` — минифицированные файлы с CRLF и очень длинными
   строками. Редактируй точечными заменами; читай и пиши файлы, не меняя
   переводы строк (в Python: `open(..., newline='')`). Диф правки одной фразы
   должен быть в 1–3 строки, а не в тысячи.
2. **Не редактируй `sitemap-0.xml` вручную** — он генерируется:
   `python3 scripts/generate_sitemap.py` (собирает self-canonical страницы без
   noindex, lastmod из git-дат). GitHub Actions пересобирает его при каждом
   push в `main`.
3. **Не трогай `frozen-assets/`, `_astro/`, `assets/`** — замороженные бандлы
   CSS/JS, на них ссылаются страницы.
4. **Факты в контенте не выдумывать.** Цифры, сроки и обещания в текстах
   («3 варианта», «аккредитив Сбербанка», «ответ до 15 минут») можно писать
   только если они уже присутствуют на этой же странице или в гайдах сайта.
5. **Канонические URL** — `https://avtonds.ru/...`; у каждой индексируемой
   страницы есть `<link rel="canonical">`. Новостные подстраницы канонизированы
   на `/news/`; `/skynomad` и `page143663496.html` — noindex, в sitemap не входят.
6. **Весь корень репозитория публикуется.** `deploy-pages.yml` грузит артефакт
   с `path: .`, а `.nojekyll` отключает фильтрацию Jekyll — любой добавленный
   в корень файл становится доступен по `https://avtonds.ru/<путь>`.
   Внутреннюю экономику (себестоимость, маржа, ставки финансирования) нельзя
   класть в файлы, попадающие в артефакт. `.claude/` из артефакта исключён
   отдельным шагом workflow — не удаляй этот шаг.

## Конфигурация Claude Code

- `.claude/skills/` — проектные скиллы. `kp-avtonds` — сборка коммерческого
  предложения (каскад себестоимости, скоринг, гейт по рынку РФ). Содержит
  внутренние ставки и маржу: файл живёт в git, но **не** в деплое (см. правило 6).
- `.claude/commands/` — слэш-команды под рутину репозитория:
  `/sitemap` (пересборка + валидация), `/crlf` (проверка переводов строк),
  `/prepush` (полный чек-лист перед push).
- `.claude/settings.json` — разрешения (`python3 scripts/*`, git) и запреты на
  запись в генерируемые и замороженные пути; хуки держат `AGENTS.md`
  синхронным с `CLAUDE.md`.

## Автоматизация (GitHub Actions)

- `.github/workflows/deploy-pages.yml` — на push в `main`: публикация статики
  на GitHub Pages (артефакт из корня, `.claude/` исключается).
- `.github/workflows/seo-automation.yml` — на push в `main`: пересборка sitemap
  (автокоммит `[skip ci]`) + отправка изменённых страниц в IndexNow
  (`scripts/indexnow_ping.py`, ключ — файл `34fc….txt` в корне).
- Секреты/ключи не перемещать и не публиковать в других файлах.

## Конвенции

- Ветки: `claude/*` или `codex/*`; PR в `main` со squash-мержем.
- В `main` напрямую не пушить (кроме автокоммитов workflow).
- `robots.txt` закрывает `/api/`, `/docs/`, `/tools/`, `/scripts/`; для Яндекса
  задан `Clean-param: quoteId /offers` — не удалять.
- Разметка Schema.org — JSON-LD в `<head>`; FAQPage добавлять только для
  видимых на странице вопросов-ответов.
- Служебные документы — в `docs/` (не индексируются), скрипты — в `scripts/`.

## Проверки перед push

- `python3 scripts/generate_sitemap.py` — завершится без ошибок, ~57 URL.
- `python3 -c "import xml.etree.ElementTree as ET; ET.parse('sitemap-0.xml')"`.
- `python3 scripts/sync_agent_docs.py --check` — AGENTS.md совпадает с CLAUDE.md.
- Для правленых страниц: `file <страница>` по-прежнему показывает
  «with CRLF line terminators» (если файл был CRLF).
