# КП АвтоНДС: заявка → расчёт → предложение

## Когда срабатывает
Есть заявка клиента на конкретную модель (или список позиций) и нужно посчитать
цену и оформить предложение. Не срабатывает для внутренней аналитики рынка
без клиента — это РАДАР.

## Шаг 0. Уточнить перед расчётом
Если в заявке не хватает — спросить одним блоком, не по одному:
- физлицо или юрлицо (ОСНО, НДС 22%) — от этого меняется весь каскад;
- вариант поставки: **до СВХ** или **под ключ** (таможня, ЭПТС, ЭРА-ГЛОНАСС, полный пакет);
- маршрут: прямое оформление РФ или через РБ;
- обязательные опции против желательных;
- срок, к которому нужна машина.
Чего не хватает — помечать `уточнить`, а не додумывать.

## Шаг 1. Отбор предложений
- Год производства 2026, пробег **до 500 км** (жёстко; свыше 1000 км не рассматриваем вообще).
- Минимум 3 актуальных предложения на модель.
- Источники — только официальные конфигураторы и конкретные карточки дилеров;
  нет карточки — ставим `source_gap`, а не среднюю цену по рынку.
- Вариант без обязательной опции **не отсеиваем** — показываем с пометкой.
- Замену модели (S500 вместо S450, GLE 400d Coupe вместо 300d) предлагаем сразу,
  отдельной строкой.

## Шаг 2. Каскад себестоимости — три уровня, всегда все три
1. **Закупка нетто ЕС** — цена export-net у поставщика.
2. **До СВХ** — выкуп +3%, фрахт (Роттердам–Питер ≈ 5 100), экспортная декларация 250,
   страховка 0,3%, финансовый транзит 1,5%.
3. **Под ключ** — пошлина 15% (рабочая оценка до классификации по ТН ВЭД),
   акциз по ст.193 НК (до 300 л.с. — 1 004 ₽/л.с., до 400 — 1 711, до 500 — 1 771,
   свыше 500 — 1 829), НДС 22%, фикс. расходы РФ 680 000 ₽
   (сбор 30к + брокер/СВХ 250к + ЭПТС/ЭРА/соответствие 300к + доставка 100к).
   Маршрут через РБ: таможня РБ = 24% от стоимости авто, логистика Минск–Москва 400;
   утильсбор входит в себестоимость **до** финансирования и маржи.
4. Сверху: финансирование 4,5% (3%/мес, максимум 1,5 месяца), маржа **6,5%**.

Все ставки и курс, взятые в расчёт, выписать явной строкой — чтобы КП можно было
пересобрать через месяц, не восстанавливая по памяти.

## Шаг 3. Гейт и скоринг
- **Гейт:** цена АСТ должна быть минимум на 5% ниже идентичного авто в РФ.
  Не проходит — пишем это прямо, а не прячем. Формулировка: `строгий GO` / `нет GO`.
- Сверка с конкурентами по параметрам и комплектации — жёсткая, позиция в позицию;
  и под заказ, и из наличия.
- Скоринг лучшего варианта — цена / опции; победитель первым, остальные ниже с разницей.
- Если Корея/Япония дешевле ЕС — добавить комментарий: срок 2–3 месяца
  и требуется софинансирование сделки.

## Шаг 4. Формат КП (одна страница на позицию)
```
# <Модель, комплектация> — КП для <клиент>, <ДД.ММ.ГГГГ>

**Итог.** <Цена под ключ> ₽ / <до СВХ> ₽ · срок <n> недель · <GO / нет GO>

## Автомобиль
Год, пробег, цвет/салон, спецификация, ключевые опции (список из заявки — отмечено ✓ / ✗)

## Цена
| Уровень | Сумма |
|---|---|
| Закупка нетто ЕС | |
| До СВХ | |
| Под ключ | |

## Условия
Схема оплаты, валютная оговорка, срок поставки, что входит в пакет документов

## Сравнение с рынком РФ
Аналог в РФ: <цена, источник> · выгода: <%>

## Что уточнить
- <пункт>
```

## Правила (одинаково каждый раз)
- Ни одной цифры без источника: цена закупки — ссылка/поставщик, цена РФ — карточка.
- Курс и дату курса фиксировать в тексте.
- Маржу клиенту не раскрывать — в КП только итоговые суммы.
- Реквизиты и подпись: ООО «АСТ», ИНН 6313553773, директор Юдин Д.В.,
  63ast@mail.ru, avtonds.ru.
- Не обещать сроков, не подтверждённых поставщиком: `ориентировочно`.
- Заблокированные для юрлиц марки (Chery, Changan, GWM/Haval, JAC) и EV через
  Киргизию/Казахстан — сразу флаг, до расчёта.
- Одна позиция = одна страница. Несколько позиций = несколько страниц + сводная таблица.

## Проверка перед выдачей
- [ ] Все три уровня каскада посчитаны и сходятся
- [ ] Гейт −5% проверен и вердикт написан явно
- [ ] У каждой цифры есть источник или пометка `source_gap`
- [ ] Обязательные опции отмечены ✓/✗ по каждому варианту
- [ ] Маржа нигде не видна клиенту
