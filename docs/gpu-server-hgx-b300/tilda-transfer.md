# Перенос страницы «Сервер NVIDIA HGX B300» на боевой avtonds.ru (Tilda)

Страница `/gpu-server-hgx-b300/` уже собрана и опубликована в staging-репозитории
на GitHub Pages, но боевой сайт avtonds.ru работает на Tilda — туда её нужно
перенести вручную через браузер, в проекте avtonds.ru на tilda.cc.

Готовый код для переноса лежит в этом репозитории:

- `docs/gpu-server-hgx-b300/tilda/head.html` — для поля страницы «HTML-код
  для HEAD» (шрифты, разметка Schema.org `Product` + `FAQPage`, счётчик
  Метрики).
- `docs/gpu-server-hgx-b300/tilda/body.html` — для блока T123 «HTML-код»: вся
  вёрстка страницы и скрипт формы. Границы нашей шапки и подвала размечены
  комментариями.

Оба файла собирает `python3 scripts/build-tilda-gpu-b300.py` из
`gpu-server-hgx-b300/index.html` — при любой правке исходной страницы
перезапусти скрипт и закоммить результат, вручную файлы в `tilda/` не править.

## Шаги

1. Открой tilda.cc → проект avtonds.ru → страницу с адресом (path)
   `gpu-server-hgx-b300`. Если такой страницы ещё нет — создай пустую
   страницу ровно с этим адресом (на него ссылаются canonical и sitemap).

2. Открой `docs/gpu-server-hgx-b300/tilda/head.html` и `.../body.html` из
   этого репозитория (ветка задачи, пока PR не смержен, иначе `main`).

3. Заголовок, описание и canonical впиши в поля SEO самой страницы Tilda —
   значения приведены в шапке `head.html`:
   - Заголовок: «Сервер NVIDIA HGX B300 8-GPU под заказ | АСТ»
   - Описание: как в комментарии `head.html`
   - Canonical: `https://avtonds.ru/gpu-server-hgx-b300/`

4. Вставь код: содержимое `head.html` — в поле «HTML-код для HEAD»,
   содержимое `body.html` — в блок T123 «HTML-код» на самой странице.

5. Шапка и подвал. В `body.html` они свои, размечены комментариями `НАЧАЛО
   НАШЕЙ ШАПКИ` / `КОНЕЦ НАШЕЙ ШАПКИ` и `НАЧАЛО НАШЕГО ПОДВАЛА` / `КОНЕЦ
   НАШЕГО ПОДВАЛА`. Реши, показывает ли эта страница общие шапку/подвал
   сайта:
   - если да и это устраивает — удали наши блоки, оставь общие;
   - если общие не нужны — отключи их в настройках страницы Tilda («Скрыть
     шапку/подвал на этой странице»), оставив наши блоки.

6. Контакты и текст мессенджеров для этой страницы. Вся вёрстка обёрнута в
   `<div id="ast-gpu-b300" data-page-kind="offer" data-offer="gpu-server-hgx-b300"
   data-ast-message="…" data-ast-phone="+7 917 011-52-18" data-ast-phone-display="…"
   data-ast-whatsapp="79170115218">` — это атрибуты, которые в снапшоте стоят
   на теге `<body>`. Рантайм `assets/ast-conversion.js` читает их именно с
   `<body>`, а на Tilda тег `<body>` общий для всего сайта, поэтому:
   - если рантайм на весь сайт ещё не подключён (см. п. 7) — можно ничего не
     делать, страница будет работать со своим текстом кнопок за счёт разметки
     внутри блока;
   - если рантайм уже подключён на уровне сайта и общая липкая панель должна
     показывать номер и текст именно этой страницы — продублируй те же пять
     атрибутов в поле «Атрибуты тега body» страницы (Настройки страницы →
     Дополнительно). Без этого общая липкая панель покажет общий номер
     +7 987 283-12-55 и обобщённый текст, а не текст про HGX B300 — это не
     ломает страницу, но раскрывает не тот номер.

7. Рантайм конверсии (липкая панель, дедупликация `ast_contact`, передача
   UTM Директа в CRM). Проверь в «Настройки сайта → HTML-код для body»,
   подключён ли он уже на весь сайт (см. `docs/etap1-measurement-conversion.md`):
   - если подключён — ничего дополнительно делать не нужно;
   - если нет — либо подключи по инструкции в том файле
     (`scripts/build-tilda-snippet.py`), либо для этой одной страницы
     липкой панели на телефоне не будет (форма и кнопки CTA работают и без
     неё — у них свой обработчик в `body.html`).

8. Счётчик Метрики (`106049767`). Если уже подключён на весь сайт в
   настройках Tilda — удали блок между `НАЧАЛО СЧЁТЧИКА` и `КОНЕЦ СЧЁТЧИКА`
   в `head.html`, иначе визиты посчитаются дважды.

9. Форма заявки. Она стучится в `https://api.avtonds.ru/api/max-page/order`,
   а если сервис недоступен — открывает WhatsApp на `+7 917 011-52-18` с
   готовым текстом заявки, так что заявка не теряется. Если заявки на
   avtonds.ru дополнительно собираются через встроенные формы Tilda (для CRM
   или почты) — добавь скрытую форму Tilda и продублируй в неё те же поля,
   как сделано для квиза в `assets/ast-conversion.js`. Если всё и так уходит
   через `api.avtonds.ru` — не нужно.

10. Опубликуй страницу и проверь:
    - открывается по адресу `avtonds.ru/gpu-server-hgx-b300`;
    - на телефоне нет горизонтальной прокрутки;
    - таблица состава прокручивается по горизонтали внутри себя, а не
      сдвигает всю страницу;
    - телефон в шапке, в блоке заявки и в подвале — `+7 917 011-52-18`;
    - нигде на странице нет слов «юрлицо» / «юридическое лицо»;
    - отправка тестовой заявки проходит без ошибок в консоли (F12 перед
      отправкой);
    - при недоступном `api.avtonds.ru` форма уводит в WhatsApp с заполненным
      текстом.

Если что-то в проекте Tilda устроено иначе, чем описано выше (например, нет
настройки «скрыть шапку для страницы») — сделай ближайший к описанному
вариант и зафиксируй отличие в ответе.
