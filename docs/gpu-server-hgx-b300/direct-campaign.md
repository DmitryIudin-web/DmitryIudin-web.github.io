## 5. Цели Метрики (счётчик 106049767)

Посадочная отправляет:

создать через `python3 scripts/metrika.py create-goals` (добавить в список) или
вручную: Метрика → Цели → JS-событие с тем же идентификатором.

## 6. Чек-лист запуска

1. Страница открывается по `https://avtonds.ru/gpu-server-hgx-b300/` после мержа в `main` (деплой — GitHub Pages).
2. В консоли страницы определён `ASTConversion`; заход с `?_ym_debug=1&utm_source=test` показывает `reachGoal` и `ast_source`.
3. Тестовая отправка формы: если приёмный API `api.avtonds.ru` не отвечает с домена Pages, форма уводит в WhatsApp с заполненным текстом — заявка не теряется. Проверить, что менеджер получает сообщение.
4. Цели из п. 5 созданы в Метрике до включения кампании.
5. Кампания на поиске: автотаргетинг выключен, минус-фразы загружены, регионы и время заданы.
6. Через 48–72 часа — отчёт «Параметры визитов → ast_source» в разрезе `utm_source_type` и `utm_term`: отсечь фразы с отказами > 60 % и без `ast_form_start`.
7. Еженедельно: стоимость `ast_contact`, доля заявок с заполненной компанией, топ-фразы. Фразы без заявок за 300+ кликов — в минус.
