# Изображения Rolls-Royce Cullinan для переноса на Tilda

Все файлы уже лежат в репозитории по адресу `https://raw.githubusercontent.com/DmitryIudin-web/DmitryIudin-web.github.io/main/assets/rolls-royce-cullinan/<имя>` и на витрине `https://dmitryiudin-web.github.io/assets/rolls-royce-cullinan/<имя>` — их можно скачать и загрузить в файловый менеджер Tilda. Для каждого кадра нужны обе версии WebP (960 px — для мобильных, 1600 px — для десктопа), у трёх ключевых кадров есть также широкий 1600 px размер. Формат JPEG (`hero-exterior-3-4.jpg`) нужен один: он используется только для превью в соцсетях (`og:image`), в вёрстке страницы не показывается.

## Как заменить пути

В `body.html` и `head.html` все ссылки на картинки имеют вид `/assets/rolls-royce-cullinan/hero-exterior-3-4-1600.webp`. После загрузки каждого файла в Tilda скопируйте выданную ссылку (обычно `https://static.tildacdn.com/...`) и замените ею путь целиком — по всем местам, где он встречается (один и тот же кадр может использоваться по нескольку раз: например, `hero-exterior-3-4-1600.webp` — в теге предзагрузки в head.html, в самом hero, в карточке версии и в галерее). Удобнее всего сделать это функцией «Найти и заменить» в текстовом редакторе перед вставкой кода в Tilda.
