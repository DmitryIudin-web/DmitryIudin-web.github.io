# Что нужно сделать вашими руками — Этап 1

Эти шаги нельзя выполнить из облака: нужен браузер, где вы залогинены в
Яндекс Метрику, Tilda и CRM. Код со стороны сайта готов и проверен
(см. `docs/etap1-audit-2026-09-03.md`) — события уходят, ждут только целей.

Порядок важен: без п. 1 и п. 2 в Метрике не будет данных, и весь этап
нельзя принять.

---

## 1. Создать цели в Метрике

### Вариант А — скриптом, само (3 минуты)

Работает по OAuth-токену, без браузера и без пароля. Запускать **со своего
компьютера**: облачные окружения домен `api-metrika.yandex.net` не пропускают.

1. Получить токен: oauth.yandex.ru -> создать приложение с правами
   «Яндекс.Метрика: получение статистики» и «Яндекс.Метрика: управление
   счётчиками» -> выпустить токен для своего аккаунта.
2. В папке репозитория выполнить:

   ```
   set METRIKA_OAUTH_TOKEN=ваш_токен
   python scripts\metrika_goals.py
   ```

   (на macOS/Linux: `METRIKA_OAUTH_TOKEN=ваш_токен python3 scripts/metrika_goals.py`)

Скрипт заведёт недостающие цели и не тронет существующие — повторный запуск
безопасен. Посмотреть, что он собирается делать, не обращаясь к API:
`python scripts\metrika_goals.py --dry-run`.

Токен нигде не сохраняется и никому не пересылается — он живёт только в
переменной окружения на вашей машине.

### Вариант Б — руками (15 минут)

metrika.yandex.ru -> счётчик **106049767** -> Настройки -> Цели -> Добавить цель.
Тип — **JavaScript-событие**. Идентификатор вводить точно, регистр важен.

| Название | Идентификатор |
|---|---|
| AST: клик CTA | `ast_cta_click` |
| AST: мессенджер | `ast_messenger_open` |
| AST: клик телефон | `ast_phone_click` |
| AST: старт формы | `ast_form_start` |
| AST: квиз | `ast_quiz_submit` |
| AST: форма | `ast_form_submit` |
| **AST: обращение** (главная) | `ast_contact` |

Цель `ast_call` создавать только после подключения коллтрекинга (пункт 7).

Существующие автоцели не удалять и не менять — они нужны для сверки.

## 2. Подключить рантайм в Tilda (5 минут)

tilda.cc → проект avtonds.ru → Настройки сайта → Ещё →
«HTML-код для вставки внутрь BODY». Вставить в конец:

```html
<!-- AST conversion etap1 start -->
<link rel="stylesheet" href="https://dmitryiudin-web.github.io/assets/ast-conversion.css?v=20260903">
<script src="https://dmitryiudin-web.github.io/assets/ast-conversion.js?v=20260903" defer></script>
<!-- AST conversion etap1 end -->
```

Затем «Опубликовать все страницы».

Без этого шага весь Этап 1 работает только на staging-снапшоте, а на боевом
avtonds.ru — нет.

## 3. Проверить, что данные пошли (10 минут)

Открыть любую страницу боевого сайта с `?_ym_debug=1`, открыть консоль
браузера, кликнуть кнопку «Написать в Telegram». В консоли должны появиться
`reachGoal` с `ast_cta_click`, `ast_messenger_open` и `ast_contact`.

Через час — Метрика → Отчёты → Конверсии: у целей должны быть ненулевые
значения. Отметить в `docs/tracking-check-2026-09.md`.

## 4. Тест сквозной цепочки до CRM (20 минут)

Отправить тестовую заявку: телефон `+7 900 000-00-01`, имя с пометкой «ТЕСТ».
Проверить по цепочке и записать, где рвётся, если рвётся:

- [ ] визит виден в Метрике (Отчёты → Конверсии → `ast_form_submit`);
- [ ] заявка пришла в CRM;
- [ ] в карточке есть `utm_source/medium/campaign`, `page`, `offer`, `ym_client_id`.

Повторить для квиза (финал «Жду звонка с расчётом») — в CRM должны быть
`scenario=quiz` и `source_detail=ast_quiz`.

Результат занести в `docs/tracking-check-2026-09.md`, раздел 2.

## 5. Фильтр роботов и сегменты (15 минут)

- Настройки счётчика → Фильтры → включить «Не учитывать роботов по строгим
  правилам и поведению».
- Сегмент **«Люди»**: Роботность = «Люди», исключить визиты < 5 сек с одной
  страницей при источнике «Прямые заходы».
- Сегмент **«Август прямые»**: 31.07–22.08.2026, источник «Прямые заходы».
  По нему посмотреть географию, устройства, отказы и 2–3 записи Вебвизора,
  чтобы понять природу всплеска (~1 300 визитов при отказах 65%).

## 6. Секрет для Telegram-автопостинга (2 минуты)

Репозиторий → Settings → Secrets and variables → Actions → New secret:
имя `TELEGRAM_BOT_TOKEN`, значение — токен бота @ASTavtomoto.
Без него workflow автопостинга не работает.

## 7. Отдельный номер для сайта (когда будет)

Подключить коллтрекинг или выделенный номер, затем сказать мне — обновлю
номер в конфиге рантайма и заведём цель `ast_call`.
