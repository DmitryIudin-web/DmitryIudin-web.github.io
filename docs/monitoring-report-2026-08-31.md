## Ручные шаги, которые может сделать только владелец

1. Создать JS-цели в Яндекс.Метрике и подключить рантайм конверсии в Tilda —
   план в `docs/tracking-check-2026-09.md` (сессия «Измерение и конверсия avtonds.ru»
   ждёт этого отчёта).
2. Добавить секрет `TELEGRAM_BOT_TOKEN` в репозиторий — без него автопостинг
   в @ASTavtomoto (PR #4) не заработает.
3. Включить ПК, чтобы отвисли Remote-Control-сессии; прогнать `tools/hermes-audit.ps1`.
4. Опубликовать исходники РАДАР в пустой репозиторий radar-monitor (лежат на ПК;
   попытки разбудить облачную сессию «РАДАР» из этой сессии заблокированы
   политикой разрешений — нужен запуск владельцем).
