# Обзор ZEEKR 9X на AutoNDS

На 13.11.2026 страница https://avtonds.ru/zeekr-9x находится в Tilda (проект 7528993, страница 281770109). Содержимое записи T123 № 4456625201 загружало https://offers-api.89-125-27-177.sslip.io/zeekr-9x-oem-20261003/index.html. При проверке страница ответила HTTP 200, а вложенный документ — HTTP 404.

## Материал

Русская версия, исходная разметка, перечень медиа и таблица оснащения взяты из [архивной ветки АСТ](https://github.com/DmitryIudin-web/avtonds-ru/tree/91d5845d1a31807c9a8fecab617f93586e79392c/oem-copies/zeekr-9x). Исходный снимок китайской страницы сделан 03.10.2026. Основные характеристики также описаны в [релизе ZEEKR](https://www.zeekrgroup.com/en/news/202509291). Длина 5 239 мм, колёсная база 3 169 мм и посадка 5/6 сверены по строкам заводской таблицы. Из семи колонок четыре относятся к шестиместной версии, три — к пятиместной.

В краткой карточке использованы три изображения исходного обзора (имена в архиве: a49d3bde0626bfc2, 7d6e0d39de30b299 и 642a8e35c3bae17c). В полной версии доступна сравнительная таблица оснащения. Демонстрационная форма, китайские цены, покупательские акции и калькулятор финансирования исключены. Фотографии и видео производителя иллюстрируют модель. Основание на публичное использование OEM-медиа отдельно в исходной ветке не зафиксировано.

## Проверка и выпуск

1. Из корня запустить `python3 scripts/restore_zeekr_9x_media.py`. Скрипт получает из исходных адресов OEM 355 ресурсов и сверяет длину и SHA-256 каждого файла, включая все 20 видео. Готовые файлы с верным хешем используются повторно. 20 постеров и изображения краткой карточки входят в Git. Затем запустить обычный статический HTTP-сервер из корня и открыть `/zeekr-9x/index.html`.
2. Проверить краткий обзор, переход в подробный, фотографии салона, шесть цветов и поворот кузова, видео, таблицу версий, возврат и открытие общей формы. Для проверки интеграции подставить фрагмент из `zeekr-9x/tilda-fragment.txt` вместо старого iframe в снимок действующей страницы. При тестировании отправки перехватывать POST к Tilda.
3. После согласования владельца опубликовать файлы через существующий GitHub Pages. При пустом кеше понадобится загрузка примерно 258 МиБ. Ошибка загрузки или хеша останавливает сборку до переключения опубликованной версии. Проверить `https://dmitryiudin-web.github.io/zeekr-9x/index.html`, фотографии, вложенный обзор и ответы на диапазонный запрос для MP4.
4. На странице Tilda заменить только блок старого обзора (включая его CSS, который фиксировал iframe поверх всей страницы, и скрипт проброса UTM) содержимым `zeekr-9x/tilda-fragment.txt`. Оставить общие скрипты, счётчик и скрипт OEM-аналитики записи. Опубликовать только эту страницу и проверить фактический адрес на телефоне и компьютере. Модель и атрибуцию формирует общая форма родительской страницы. Обработчик принимает действие только из данного iframe с адреса GitHub Pages.
5. Перед заменой сохранить предыдущую редакцию Tilda. Для отката можно вернуть редакцию страницы и переопубликовать её. Эта редакция ссылается на прежний адрес с 404. Если сбой только в полном обзоре, краткая карточка и её форма работают независимо от видео и каталога OEM.
