# Регламент работы нескольких агентов (Этап 4)

Как продолжать работу, когда у агента кончился лимит. Настройка инструментов —
`docs/agents-setup.md`. Технические правила репозитория — `CLAUDE.md`.

> `docs/` публикуется на сайте (закрыт только в robots.txt). Ключи, ставки,
> маржу и данные клиентов сюда не писать.

## 1. Порядок переключения

| № | Агент | Когда |
|---|---|---|
| 1 | Claude Code (подписка) | по умолчанию |
| 2 | Codex (подписка) | кончился лимит Claude |
| 3 | Claude Code / Cline на Kimi или Qwen (OpenRouter, оплата за токены) | кончились обе подписки |
| 4 | Cline на DeepSeek | только рутина, экономия бюджета |
| 5 | Copilot / локальная модель (Ollama) | всё остальное недоступно |

Лимиты подписок восстанавливаются сами — не обязательно переключаться,
если задача терпит несколько часов.

## 2. Какая модель под какую задачу

| Задача | Минимум | Нельзя |
|---|---|---|
| КП, расчёты с внутренними ставками (`/kp-avtonds`) | Claude Code / Codex на своей подписке, или локальная модель | внешние дешёвые провайдеры (Kimi, Qwen, DeepSeek, OpenRouter) |
| Логика `assets/ast-conversion.js`, workflow, скрипты | Claude / Codex; Kimi — только с ревью | DeepSeek Flash без ревью |
| SEO: canonical, JSON-LD, robots, редиректы | Claude / Codex / Kimi | — |
| Тексты страниц, правка фраз, опечатки | любая из списка | — |
| Обновление Tilda-снапшота, редизайн страницы | Claude / Codex; PR с меткой `allow-frozen` / `allow-rewrite` | — |

Правило 4 из `CLAUDE.md` (факты не выдумывать) касается всех моделей —
дешёвые модели нарушают его чаще: цифры в текстах проверять глазами.

## 3. Цикл работы любого агента

1. **Начало.** `git pull`, прочитать верхнюю запись в `docs/HANDOFF.md`.
2. **Ветка** `<агент>/<задача>`: `claude/…`, `codex/…`, `cline/…`, `kimi/…`.
   Один агент — одна ветка; продолжая чужую задачу, работать в её ветке.
3. **Правки** точечные (`CLAUDE.md`, правило 1).
4. **Проверка** `python3 scripts/check.py` → «ИТОГ: OK». Pre-commit хук
   запускает её сам; `--no-verify` — только осознанно.
5. **Коммит часто**: лимит может кончиться посреди задачи.
6. **PR в `main`**, squash-мерж только при зелёной проверке `PR checks`.

## 4. Передача смены (лимит кончился посреди задачи)

1. Дописать запись **сверху** в `docs/HANDOFF.md` по шаблону: что сделано,
   где остановился, следующий шаг, результат `check.py`.
2. Закоммитить **вместе с записью** и запушить всё, даже незаконченное
   (`WIP:` в сообщении). Иначе запись останется только на этом компьютере.
3. Следующему агенту первым сообщением: «Прочитай `docs/HANDOFF.md`
   и продолжи задачу в ветке `<ветка>`».

Если агент оборвался, не успев записать: сделайте запись сами по
`git log` / `git diff` — две строки достаточно — и тоже закоммитьте и запушьте.

## 5. Ревью PR

- Автоматически: `PR checks` (`scripts/check.py`) — на каждом PR.
- Код-ревью: Codex review, пока есть лимит; иначе `/code-review` в Claude Code
  или ревью Copilot. Для текстов страниц достаточно `check.py` и просмотра
  дифа; для `ast-conversion.js`, workflow и скриптов — ревью обязательно.
- PR от агентов уровня 3–5 перед мержем смотреть глазами: диф 1–3 строки
  на страницу, нет новых цифр и обещаний.

## 6. Бюджет

- OpenRouter: месячный лимит на ключе. Раз в месяц смотреть расход
  и сравнивать со стоимостью второй подписки — если запас тратится каждую
  неделю, дешевле поднять тариф основной.
- Дорогие модели — только задачи из верхних строк таблицы §2.

## 8. Если что-то пошло не так

| Ситуация | Действие |
|---|---|
| `check.py`: `[crlf]` или `[rewrite]` | `git checkout HEAD -- <файл>` (откатывает и индекс, и файл; просто `git checkout -- <файл>` после `git add` не поможет), повторить правку точечно (или сменить модель) |
| `check.py`: `[frozen]` | откатить файл; если правка нужна (снапшот Tilda) — PR с меткой `allow-frozen` |
| `check.py`: `[sitemap]` | `python3 scripts/generate_sitemap.py`, руками не править |
| `check.py`: `[docs]` | правку перенести в `CLAUDE.md`, затем `python3 scripts/sync_agent_docs.py` |
| Агент «застрял», ходит по кругу | остановить, записать HANDOFF, переключиться на модель уровнем выше |
| Сломанное уже в `main` | `git revert <коммит>` через PR, не правка поверх в спешке |
