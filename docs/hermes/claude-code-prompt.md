# Задание для продолжения единого проекта Hermes

Код Windows-подключения и VPS-комплекта теперь общий. Передайте агенту текст ниже,
указав только необходимые пути или выбранный адрес сервера. Секреты в чат не вставляйте.

```text
Продолжи единый проект Hermes в PR №28 репозитория
https://github.com/DmitryIudin-web/DmitryIudin-web.github.io.
Ветка: claude/hermes-telegram-setup-3aeo3t.

Прочитай AGENTS.md и docs/hermes/README.md. Сначала проверь существующий
Hermes, его HERMES_HOME и runtime. Не исходи из предположения, что его нет.
Сохраняй секреты, OAuth, память, сессии, модели и задания в текущем приватном
профиле; ничего из них не копируй в публичный репозиторий.

Для подключения существующей установки используй connect-existing.ps1:
сначала предпросмотр, затем разрешённое применение и отдельный read-back.
Не выдавай сохранённый YAML за действующую защиту: старый runtime 0.17.0
не исполняет approvals.deny. Неподдерживаемый runtime должен оставаться
явно помеченным upgrade_required до проверенного обновления.

Для нового VPS сначала должен быть выбран конкретный сервер и разрешён запуск.
Только после этого используй bootstrap-vps.sh. Существующий токен не запускай
одновременно в двух gateway. Перед переключением подготовь резервную копию,
проверку новой версии и возврат прежнего процесса. Реальный ответ бота
проверяет владелец своим сообщением; самостоятельно людям ничего не отправляй.

Никаких push в main, merge, публикаций, CRM-записей, расходов и клиентских
сообщений без отдельного разрешения. Заверши доказательствами: commit/PR,
проверки, фактическая версия и состояние процесса, применённые настройки,
оставшиеся разрывы и следующий подготовленный шаг.
```
