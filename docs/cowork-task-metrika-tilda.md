# Задание для Cowork (Claude на вашем компьютере) — настройка Метрики и Tilda

Откройте приложение Claude (Cowork) на компьютере, где вы залогинены в
Яндекс Метрику и Tilda, и отправьте ему текст ниже целиком. Он сделает всё
через ваш браузер; от вас потребуется только подтверждать действия.

---

Ты работаешь в моём браузере. Выполни настройку этапа 1 «Измерение +
конверсия» для сайта avtonds.ru. Счётчик Яндекс Метрики: **106049767**.

## 1. Цели в Метрике

Открой https://metrika.yandex.ru → счётчик 106049767 → Настройки → Цели.
Создай 6 целей типа **JavaScript-событие** (идентификатор события — точно как
указано, регистр важен):

| Название цели | Идентификатор |
|---|---|
| AST: клик CTA | `ast_cta_click` |
| AST: мессенджер | `ast_messenger_open` |
| AST: клик телефон | `ast_phone_click` |
| AST: квиз | `ast_quiz_submit` |
| AST: форма | `ast_form_submit` |
| AST: обращение | `ast_contact` |

Цель «AST: обращение» — главная; если есть флажок «доход/основная цель», не
включай, просто создай. Существующие цели и автоцели НЕ удаляй и не меняй.

## 2. Фильтр роботов и сегменты

- Настройки счётчика → вкладка «Фильтры» → включи «Не учитывать роботов по
  строгим правилам и поведению» (сохрани).
- Создай сохранённый сегмент **«Люди»**: Отчёты → любой отчёт → Сегментация:
  Роботность = «Люди»; добавь условие-исключение: НЕ (источник «Прямые заходы»
  И время на сайте < 5 сек И глубина = 1 страница). Сохрани как «Люди».
- Создай сегмент **«Август прямые»**: период 31.07.2026–22.08.2026, источник
  трафика = «Прямые заходы». Сохрани. Посмотри по нему географию, устройства,
  отказы и 2–3 записи Вебвизора; напиши краткий вывод: боты / рассылка /
  реальные люди.

## 3. Подключение кода в Tilda

Открой https://tilda.cc → проект avtonds.ru → Настройки сайта → Ещё →
«HTML-код для вставки внутрь BODY» (в конец body). Вставь:

```html
<!-- AST conversion etap1 start -->
<link rel="stylesheet" href="https://dmitryiudin-web.github.io/assets/ast-conversion.css?v=20260831">
<script src="https://dmitryiudin-web.github.io/assets/ast-conversion.js?v=20260831" defer></script>
<!-- AST conversion etap1 end -->
```

Сохрани и нажми «Опубликовать все страницы».
(Файлы раздаются со staging-домена GitHub Pages; они появятся там после
мержа PR №1 в main. Если файл по ссылке отдаёт 404 — сначала попроси
смержить PR https://github.com/DmitryIudin-web/DmitryIudin-web.github.io/pull/1.)

## 4. Проверка (A3 из tracking-check)

1. Открой https://avtonds.ru/?_ym_debug=1 в обычной вкладке. В консоли
   браузера при кликах по кнопкам Telegram/телефона должны появляться
   `reachGoal` c `ast_cta_click`, `ast_messenger_open`, `ast_contact`.
2. Отправь тестовую заявку через форму: телефон `+7 900 000-00-01`, в
   комментарии «ТЕСТ». Проверь через 10–15 минут: Метрика → Отчёты →
   Конверсии → цель формы; и что заявка пришла в CRM с пометкой ТЕСТ.
3. Результаты запиши: какие цели сработали, дошла ли заявка до CRM, где
   разрыв, если есть.
