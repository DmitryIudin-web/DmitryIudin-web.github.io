# Передача смены между агентами

локальная модель), следующий видит только репозиторий, не чат. Перед
переключением агент (или вы) коммитит работу и дописывает запись **сверху**.

> `docs/` публикуется на сайте (закрыт только в robots.txt). Никакой внутренней
> экономики — себестоимости, маржи, ставок, данных клиентов — здесь не писать.
